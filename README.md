# Guardian Monitor updates

This repo holds the update files for Guardian Monitor (Mac and Windows). The app's **Update** button reads `version.json`, downloads the listed files, checks each file's SHA-256 fingerprint, and installs them.

Current version: **5.1**

5.1: Catches Pokémon Center queues that were hiding from the page reader (text inside frames and hidden page parts). Queue alerts now say when a drop isn't English, e.g. 'German TCG drop, NOT English', and include the store's notice. The log shows what each check read.
