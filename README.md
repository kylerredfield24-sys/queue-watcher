# Guardian Monitor updates

This repo holds the update files for Guardian Monitor (Mac and Windows). The app's **Update** button reads `version.json`, downloads the listed files, checks each file's SHA-256 fingerprint, and installs them.

Current version: **3.7**

Computer health: watches temperature, processor and memory, eases off or pauses if the computer runs hot (Protect / Warn only / Off), and closes stuck hidden Chrome windows. Also fixes a rare bug where settings could reset.
