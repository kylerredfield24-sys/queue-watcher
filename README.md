# Guardian Monitor updates

This repo holds the update files for Guardian Monitor (Mac and Windows). The app's **Update** button reads `version.json`, downloads the listed files, checks each file's SHA-256 fingerprint, and installs them.

Current version: **4.6**

4.6: Walmart now checks Pokémon card products sold by Walmart at MSRP (plus drawings). Each store has its own MSRP list, with a small rounding cushion. Fixed Best Buy reading its new product links. Amazon robot checks are recognized and it backs off. Status shows how many products each store saw.
