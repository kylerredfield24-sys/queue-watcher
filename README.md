# Guardian Monitor updates

This repo holds the update files for Guardian Monitor (Mac and Windows). The app's **Update** button reads `version.json`, downloads the listed files, checks each file's SHA-256 fingerprint, and installs them.

Current version: **4.2**

4.2: Best Buy checker. Pokémon card products at MSRP (no merch) plus Best Buy invite drawings, with its own Discord channel and @bestbuy role. Set channels from your phone (webhook bestbuy <link>), and turn store checkers on/off (bestbuy on/off).
