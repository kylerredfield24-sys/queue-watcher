# Guardian Monitor updates

This repo holds the update files for Guardian Monitor (Mac and Windows). The app's **Update** button reads `version.json`, downloads the listed files, checks each file's SHA-256 fingerprint, and installs them.

Current version: **4.0**

4.0: if the Pokémon Center tab gets lost on Mac, it finds it again or opens a new one and keeps watching (instead of stopping). Update from your phone: you get an 'Update ready' notification with an Update now button, or send 'update'.
