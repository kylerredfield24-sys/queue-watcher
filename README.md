# Guardian Monitor updates

This repo holds the update files for Guardian Monitor (Mac and Windows). The app's **Update** button reads `version.json`, downloads the listed files, checks each file's SHA-256 fingerprint, and installs them.

Current version: **5.2**

5.2: Captchas now ping your phone right away as an urgent alert. On Pokémon Center it keeps the tab open (no refresh), brings it to the front, and resumes watching once you solve it. Gentler checking: Pokémon Center checks half as often outside drop hours, store checkers space out page loads more, and a store that showed a robot check is checked half as often for 3 hours.
